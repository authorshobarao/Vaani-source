We are writing because your description to preregister this computer program indicates that the program uses integrated AI. It is unclear whether and how AI technology is being used in the creation of your program.

Copyright protects human works of authorship. It does not protect works produced by a machine or mere mechanical process. If a work's traditional elements of authorship were produced by a machine, the work lacks human authorship and the Office will not preregister it.

Works containing AI-generated material may also contain sufficient human authorship to support a preregistration claim. In these cases, copyright will only protect the human-authored aspects of the work. In such cases, the written description should indicate the part of the work that was created by human authorship. Therefore, if this work includes human authorship, please provide a new description for your computer program using the guideline below. When completing your revised description, please specify what part of your program is being created by human authorship. Or, let us know if the situation is otherwise.

For a computer program: Describe the nature, purpose, and function of the computer program, including information such as its approximate length (if known), any particular organization or structure in which the program has been created; any information concerning the computer language in which it is written; the form in which it is expected to be published, e.g., as an online-only product; the version, if known, which is expected to be the published version.

For additional information, please see the Office's recently-issued guidance on works containing AI-generated material.  https://www.copyright.gov/ai/ai_policy_guidance.pdf.
